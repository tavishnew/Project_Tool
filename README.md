# Project Tool

This is a project management tool with a React/TypeScript frontend and a Node.js/Express backend.

## Features
- Authentication
- Project management
- Task management

## Setup
1. Install dependencies: `npm install` in both root and frontend directories
2. Set up database: run database migrations (if any)
3. Start backend: `npm start` in backend directory
4. Start frontend: `npm run dev` in frontend directory

## Current Status
- Backend routes for auth, projects, tasks
- Frontend with basic routing and component structure
